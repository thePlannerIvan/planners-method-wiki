M01

品牌策略开发

mod_brand-strategy 7 个方法

模块「品牌策略开发」新增 2 个可复用方法，源自 3 个案例（某运动品牌健步文化策略、某运动品牌跑步户外策略、某童装品牌升级），经跨案例验证。（版本 7.0.3 · 批准 2026-07-28）

  • 项目需包含与品牌策略开发相关的分析材料，包括市场环境、消费者洞察、品牌现状等
  • 分析单元需通过B2分段验证，并经过品牌名预检
  • 用于品牌诊断与再定位场景时，需有至少两个维度的品牌表现数据（市场表现、消费者认知、价格定位等）
Use when适用条件
  • 品牌面临认知老化或低价值感问题，需要提升溢价空间
  • 存在可捕捉的群体性社会情绪（压力、焦虑、内卷等），且与品类使用场景相关
  • 品牌有差异化功能可以支撑新价值主张
  • 目标消费者对生活方式的关注超越了对产品功能的基本需求
Skip when跳过条件
  • 品类高度理性（如工业品、B2B），消费者购买决策主要由功能参数驱动
  • 品牌已有极强的价值认知，不需要通过情绪驱动重建
  • 缺乏消费者对品类的情感连结数据或文化洞察素材
Inputs所需输入
  • 社会文化趋势报告或大数据趋势洞察（如小红书趋势、社会调查数据）
  • 消费者对品类的已有认知和情感关联调研
  • 品牌现有功能优势和科技资产梳理
  • 竞品价值主张和品牌策略对比
  • 消费者日常使用场景和痛点调研
Operations操作步骤
  1. 扫描时代情绪：通过社会趋势报告、社交媒体话题、消费者调研捕捉当下的群体性压力和渴望，识别与品类使用场景相关的情绪锚点
  2. 连接品类功能与情绪价值：梳理品牌/品类的核心功能利益，找到能够回应时代情绪的功能支点，将'功能利益'升维为'精神价值'
  3. 建立从文化洞察到品牌利益的逻辑链：按'时代痛点→消费者渴望→品类价值→品牌利益→传播主张'的层次构建完整推导
  4. 传播主张提炼：基于逻辑链输出品牌传播主张和战役主题，核心主张应既能打动情感又能关联功能
  5. 验证主张的泛化性：将主张核心理念与不同场景、人群、产品线进行匹配测试，确保有足够的传播扩展性
Page structure页面表达
  • P1 · 趋势背景与情绪锚点
    概述目标人群所处的时代背景和群体性情绪（压力、焦虑、渴望等）。展示可获取的趋势数据或社会观察，建立品类使用场景与情绪锚点的关联。不需要全面数据，1-2个有说服力的趋势信号即可
  • P2 · 从功能到价值的逻辑链
    展示品牌功能利益如何回应时代情绪的推导逻辑。用流程图或层级框架呈现'时代痛点→消费者渴望→品类价值→品牌利益→传播主张'的完整链路。每个环节写清楚'因为X，所以Y'的因果关系
  • P3 · 品牌价值主张
    呈现核心品牌主张和传播主题。包含主张文案、支撑论据（功能支撑点+情感回应力），以及1-2个不同侧面的Option供选择。每版Option附一句话说明它回应什么情绪/场景
  • P4 · 主张扩展性检验
    检验主张在不同人群、场景、产品线下的适用性。可以是矩阵、表格或要点列表——核心是展示主张有足够的弹性空间，不只在单一场景成立
Outputs预期输出
  • 时代情绪洞察报告（痛点/渴望/趋势）
  • 品牌价值主张（从功能到情感的完整论点）
  • 传播战役核心主题
  • 品牌价值提升的传播策略框架
Failure modes失效模式
  • 将单一社会现象标签化、表面化，未深入分析其与品类的真实关联
  • 价值主张过于精神化而脱离产品实质，造成信任鸿沟
  • 情绪洞察年份性过强，缺乏跨年度的持续性
Boundaries适用边界
  • 该方法主要适用于面向C端、有较强情感属性或生活方式关联的品类
  • 情绪洞察需要建立在真实消费者数据而非直觉判断上
  • 跨文化应用时需重新校准本地情绪锚点
Evidence案例证据

源自某运动品牌健步系列传播策略：从'打工人亚健康/内卷/疲惫'时代情绪出发，通过'走路为生活减负'连接舒适科技，推导出'为走路减负，为生活减负'品牌主张

时代情绪驱动型品牌文化升级法

适用条件
  • 品牌面临认知老化或低价值感问题，需要提升情感价值和溢价
  • 存在可捕捉的群体性社会情绪，且与品类使用场景相关
  • 品类使用行为具有足够的社会可见性，可以承载文化意义
  • 品牌有一定用户基础，可以围绕文化概念建立社群
操作步骤
  1. 从宏观社会情绪中提炼与品类使用场景相关的核心文化张力
  2. 诊断品牌当前在消费者心智中的认知标签（年龄/时尚度/使用动机/情感联想）
  3. 对消费者使用行为进行场景化分类，识别可承载文化价值的场景
  4. 将功能行为重新定义为文化行为，建立品牌文化概念命名
  5. 定义品牌文化的核心主张与价值观表述
  6. 将文化主张分解为可独立传播的内容支柱和社交话题

Use when适用条件
  • 品牌出现增长停滞或市场份额下滑信号
  • 需要同时从市场表现、消费者认知、产品价格三个维度分析问题
  • 有品类和竞品的对比数据可作为参照基准
  • 需要产出清晰的战略优先级和破局方向
Skip when跳过条件
  • 品牌战略方向已经决策且执行层面问题为主
  • 缺乏至少两个维度的品牌诊断数据
  • 品类处于爆发增长期，增长问题不突出
Inputs所需输入
  • 品牌销量/市场份额历史数据（按渠道、品类维度拆分）
  • 消费者品牌认知调研（年龄画像、品牌标签、购买动机）
  • 产品矩阵与价格带分布
  • 竞品增长速度与市场表现对比数据
  • 品类市场容量与增长空间数据
Operations操作步骤
  1. 生意维度诊断：分析销量/份额的趋势变化，识别增长瓶颈在哪些渠道、品类、价格带，定位'量'和'价'的问题分别来自哪里
  2. 用户维度诊断：分析消费者画像变化趋势，识别用户年龄结构是否趋老，品牌在消费者心中的标签属性（如时尚度、科技感、性价比等），以及标签是否存在负面迁移
  3. 价格维度诊断：梳理产品矩阵和价格带分布，判断是否存在均价下行压力或高端线销售占比不足，识别提价空间和目标
  4. 竞品维度交叉验证：将以上三个维度的发现与竞品同期表现对比，判断问题是行业性的还是品牌独有
  5. 战略破局提炼：综合三维度诊断，识别最关键的1-2个杠杆点，提出优先级明确的'做什么→为什么→怎么做'的战略方向
Page structure页面表达
  • P1 · 品牌诊断框架
    展示品牌诊断的多维框架（生意/用户/价格三个维度），说明为什么要从这三个维度进行分析，以及各维度的诊断逻辑和判断标准
  • P2 · 维度一：生意表现
    展示品牌销量/份额的趋势变化，识别增长瓶颈的位置（渠道/品类/价格带）。可以用趋势图或对比表，核心是回答'增长卡在哪里'
  • P3 · 维度二：用户认知
    展示消费者品牌认知状况——用户画像是否趋老、品牌标签是否负面变化、品牌吸引力是否下降。有调研数据用数据，没有则用定性观察或渠道反馈
  • P4 · 维度三：价格结构
    展示产品矩阵与价格带分布，判断是否存在均价下行压力或高端线不足。核心是回答'品牌是否有提价空间、在哪里提、消费者是否接受'
  • P5 · 破局方向与优先级
    综合三维度诊断结论，识别最关键的战略杠杆点。按优先级列出破局方向，每个方向说明'做什么→为什么是这个→预期效果'
Outputs预期输出
  • 三维品牌健康度诊断报告
  • 品牌问题优先级矩阵
  • 战略破局方向与关键行动建议
  • 品类增长空间与品牌可达目标
Failure modes失效模式
  • 诊断维度过于全面但没有优先级排序，战略方向不聚焦
  • 将现象误判为根源（如将'增长慢'归因于单一因素）
  • 数据维度不够导致结论偏差
  • 诊断结论过于悲观或乐观，缺乏平衡视角
Boundaries适用边界
  • 诊断需要多源数据验证，单一数据源的结论置信度应标注
  • 跨品类应用时，品类增长阶段不同（导入期vs成熟期）诊断焦点应调整
Evidence案例证据

源自某运动品牌健步系列（增长乏力+老年人标签+价格提升需求）和某童装品牌升级（增速放缓+核心业务指标下滑+客群老化+产品力欠佳）两个案例的共同诊断框架

品类进入的五步市场分析链

适用条件
  • 品牌考虑进入一个已有一定规模但自身尚未涉足的品类
  • 需系统评估品类进入吸引力和可行性
  • 品类中已有清晰竞争分层
操作步骤
  1. 扫描目标品类整体规模、增速和品类生命周期阶段
  2. 分解品类结构：识别各子品类规模占比、增长动力和消费者渗透率
  3. 捕捉推动品类增长的关键消费趋势并评估可持续性
  4. 分层竞争格局：按国际品牌/本土大众/新兴DTC/跨界品牌四类竞争者分层
  5. 对照品牌自身资产，判断品牌在品类中的独特进入位置

  • 产品完全由消费者共创设计，需求验证充分
  • 品类高度技术驱动，消费者体验差异主要体现在性能参数

  2. 消费者反馈收集：按痛点的严重程度和频率，整理消费者对现有产品的真实不满和使用障碍
  3. 鸿沟映射：将设计假设与消费者反馈逐一对比，标注'假设正确/假设错误/重要疏漏'三类关系，量化差距规模

    整理消费者对产品的真实评价和不满。不论数据形式（评论/投诉/问卷/访谈），核心是呈现消费者实际在意的点与团队假设的差异。可以用痛点清单或分类框架组织
  • P3 · 假设与现实差异分析

Use when适用条件

  • 有可获取的社会趋势报告、消费者行为变化数据
  • 需要从宏观趋势出发推导品类进入或扩张决策

  • 品类受政策、技术等非消费者趋势的刚性因素驱动为主

Inputs所需输入

    概述影响品类的消费者生活方式趋势变化。可以从平台报告、社会观察、消费数据等任何可用来源提炼，核心是回答'消费者在发生什么变化，这对品类意味着什么'
  • P2 · 品类机会评估
    将趋势信号转化为品类层面的机会判断：品类规模与增长空间、竞争格局（谁在、多拥挤）、消费者需求缺口。不需要精确数字，趋势判断+定性评估即可
  • P3 · 品牌适配性判断
    评估品牌进入该品类的可行性：品牌核心能力是否匹配、消费者认知是否有基础、渠道供应链是否支持。从战略一致性角度判断是'应该做'还是'能做'还是'两可'
  • P4 · 进入策略与节奏
    如果结论是进入，输出品类定位建议和分阶段推进节奏（试水→验证→放量）。如果结论是不进入或不急于进入，说明判断理由和需要等待的信号条件
