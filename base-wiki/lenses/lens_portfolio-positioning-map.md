# 多品牌组合竞争定位地图

## 解决的问题

如何在一张图上展示多品牌在竞争空间中的位置并为每个品牌分配组合角色？

## 适用与跳过条件

### 适用条件
- 多品牌同品类运营
- 品类有升级分化趋势

### 跳过条件
- 单品牌不需要
- 价格与需求维度不适用

## 所需输入

- 各品牌定位信息
- 品类竞争格局
- 消费升级趋势

## 分析操作步骤

1. 构建价格×需求层次坐标系
2. 标示各品牌和竞品位置
3. 结合趋势标注策略方向
4. 检测内部蚕食风险

## 页面表达结构

### P1 · 定位坐标系全貌

构建竞争坐标系展示各品牌位置
回答：各品牌在竞争空间中的位置？
证据：品牌定位；竞品数据；趋势

- **论证目的**：构建竞争坐标系展示各品牌位置
- **回答问题**：各品牌在竞争空间中的位置？
- **所需证据**：品牌定位；竞品数据；趋势
- **信息关系**：hierarchical
- **承接来源**：从品类分析承接
- **推向后续**：为独立分析提供边界
- **常见误用**：不只展示现状不标注方向

### P2 · 组合角色与区隔

明确各品牌角色和区隔策略
回答：各自角色？如何避免内耗？
证据：定位地图；各品牌优势

- **论证目的**：明确各品牌角色和区隔策略
- **回答问题**：各自角色？如何避免内耗？
- **所需证据**：定位地图；各品牌优势
- **信息关系**：comparative
- **承接来源**：从地图读取区间
- **推向后续**：为独立分析提供约束
- **常见误用**：不给所有品牌同样角色

## 输出与失效边界

### 预期输出
- 竞争定位地图
- 组合角色描述
- 蚕食风险检测
- 调整建议

### 失效模式
- 地图太复杂无法指导
- 角色与实际定位不一致
- 仅描述现状无方向

### 适用边界
- 只提供框架不替代品牌深度审计
- 坐标维度需根据品类调整
