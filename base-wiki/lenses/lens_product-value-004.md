# 核心技术跨产品线差异化价值定位

## 解决的问题

当品牌拥有可跨产品线使用的核心技术/专利时，如何将该技术在不同产品线上做差异化的价值表达，避免产品线间的自我竞争？

## 适用与跳过条件

### 适用条件
- 品牌拥有可跨多个产品线共享的核心技术或专利

### 跳过条件
- 品牌没有跨产品线共享的核心技术

## 所需输入

- 核心技术/专利的技术参数
- 消费需求金字塔模型
- 各产品线的技术规格和定位

## 分析操作步骤

1. 将核心技术拆解为技术参数和消费者可感知的价值维度
2. 分析技术价值在消费者需求金字塔上的定位：从基础功能需求到高端差异化需求的跨级提升路径
3. 为不同定位的产品线设计差异化的技术价值表达，确保各产品线间不互相侵蚀
4. 按使用场景和人群需求区隔不同产品线，确保每个产品线有独立的价值主张和受众
