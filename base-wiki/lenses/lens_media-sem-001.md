# 搜索关键词分层策略

## 解决的问题

如何基于搜索意图设计多层次的关键词矩阵，为每层设定差异化的搜索目标和预算权重？

## 适用与跳过条件

### 适用条件
- 品牌正在进行或计划开始搜索引擎营销
- 品类搜索量足够支撑SEM的规模效应

### 跳过条件
- 品类搜索量过低导致SEM效率不高

## 所需输入

- 品牌产品线信息
- 品类搜索词数据
- 消费者搜索行为数据
- 平台投放工具
- 竞品SEM策略参考

## 分析操作步骤

1. 按搜索意图将关键词分层（品牌词/品类词/场景词/竞品词），定义每层的搜索目标和竞价策略
2. 为每层梳理具体关键词并评估搜索量/竞争度/预估成本
3. 设计各层关键词与落地页的匹配策略
4. 按关键词层级分配预算，预估各层效果和整体ROI
