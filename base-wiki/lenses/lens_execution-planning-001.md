# 年度预算分配与传播节奏规划

## 解决的问题

如何将传播周期划分为清晰阶段，按阶段分配预算，并建立完整的KPI体系？

## 适用与跳过条件

### 适用条件
- 品牌需要规划年度或项目周期的传播节奏和预算分配
- 已有品牌传播目标和总预算

### 跳过条件
- 项目只需规划单一季度或单一Campaign的预算

## 所需输入

- 项目/年度总预算
- 产品线/业务线清单与优先级
- 营销节点日历
- 各渠道成本和效能基准

## 分析操作步骤

1. 划分传播周期为3-5个阶段（如建立期→放大期→沉淀期），定义每阶段的核心目标和策略重心
2. 按阶段分配预算（金额+占比），形成预算矩阵
3. 设计预算结构（达人种草/信息流投放/品牌官方内容等各项占比），说明结构设计的策略依据
4. 设定各阶段的KPI体系和关键里程碑
