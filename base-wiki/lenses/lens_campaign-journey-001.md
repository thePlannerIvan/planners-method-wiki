# 平台IP合作匹配与Campaign规划

## 解决的问题

如何将品牌营销节点与平台IP资源系统匹配，设计从背书到口碑到曝光的多层合作框架？

## 适用与跳过条件

### 适用条件
- 品牌需要利用平台的IP资源（如电商节点IP、内容平台主题活动）进行整合营销
- 已有品牌年度核心主张和传播目标，可以对照规划IP合作

### 跳过条件
- 品牌预算或策略不支持IP合作的规模和复杂度

## 所需输入

- 品牌年度核心主张与传播目标
- 平台可用IP资源列表
- 品牌全年营销节点日历
- 目标人群画像与触媒偏好

## 分析操作步骤

1. 梳理品牌自身营销节点与平台IP资源的匹配点，按优先级排序
2. 设计递进式IP合作框架：背书层（建立信任）→口碑层（扩大影响）→曝光层（规模化触达），明确各层目标和核心动作
3. 规划三层执行方案：品牌官方层/KOL层/UGC层，明确各层内容形式和资源分配
4. 设计备选方案以应对IP资源变动，整合IP排期到品牌全年传播日历
