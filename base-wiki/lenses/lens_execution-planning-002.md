# 年度内容日历与主题规划

## 解决的问题

如何规划年度Campaign主题和月度Always-on内容节奏，使品牌传播既有爆发力又有日常渗透力？

## 适用与跳过条件

### 适用条件
- 品牌需要全年内容规划而非单次执行

### 跳过条件
- 品牌只需短期（1-3个月）的内容规划

## 所需输入

- 年度品牌/传播主题
- 产品上市节奏
- 节日/节点日历
- 目标人群内容偏好

## 分析操作步骤

1. 确定季度Campaign主题，确保与品牌年度核心主题保持一致
2. 按月度规划Always-on内容的主题方向和发布节奏
3. 将各内容类型匹配到合适的目标人群和发布平台
4. 整合为年度内容日历总览，标注Campaign爆发期和日常维护期的资源分配
