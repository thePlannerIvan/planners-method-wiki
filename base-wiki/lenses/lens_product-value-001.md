# 分消费者群体的产品偏好与产品线规划

## 解决的问题

如何基于不同消费者群体（存量用户vs增量用户）的产品偏好差异，针对性地规划产品线以实现增长？

## 适用与跳过条件

### 适用条件
- 需要基于消费者群体差异来规划产品线和定位
- 已有不同消费者群体的产品偏好调研数据

### 跳过条件
- 产品线已确定且不需要调整

## 所需输入

- 存量用户vs增量用户产品偏好调研
- 品类相关消费趋势数据
- 消费者概念测试反馈
- 竞品产品线对标信息

## 分析操作步骤

1. 划分存量用户和增量用户，对比两组在产品形态/功能/价位上的偏好差异
2. 建立品类的完整定位频谱（从基础功能型到高端享受型），标注品牌当前位置和可扩展方向
3. 针对增量用户（轻度/流失/潜在）设计降低使用门槛、强化品类价值的产品策略
4. 针对存量用户按需求亚型设计差异化产品线，规划从入门到高端的完整产品线布局
