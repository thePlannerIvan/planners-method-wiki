# Planners Method Wiki · 方法目录

> **定位**：可复用的策略分析与论证方法库（Karpathy LLM Wiki）。按问题查找方法，阅读对应方法页中的操作步骤与「页面表达结构」，不把方法中的历史案例当成当前项目事实。

## 使用规则

- **查询**：先浏览本索引定位 1–2 个候选方法，再 `read_file` 打开对应的 `lenses/<lens_id>.md` 全文（或用 `node scripts/query-wiki.mjs --query "关键词"`）。
- **维护**：按 [SCHEMA.md](SCHEMA.md) 新增或修订 `lenses/*.md`，同步更新本索引与 [log.md](log.md)，再跑 `lint-wiki.mjs` 与 `build-wiki-viewer.mjs`。
